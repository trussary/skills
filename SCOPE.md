# Scope

This repo is the workflow Trussary uses on its own projects, published so others can use it. Issues are for changes to the skills, subagents, hooks and tools.

An issue stays open when it describes something that went wrong in a real session (what you ran, what the skill did, what you expected), and the fix would help any project using the workflow. A tweak that suits one project goes in that project's `docs/agents/*.md` or `CLAUDE.md`. An issue that can't be judged gets one round of questions and `needs-info`; with no reply in 14 days it is closed as "not planned".
